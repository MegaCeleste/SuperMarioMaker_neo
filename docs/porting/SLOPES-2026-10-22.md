## Implemented slice

**Latest correction: irregular connected terrain.** The two later screenshots
showed central/high-end pillars with deep concave gaps below the slope. The
previous single-cell-only correction invented a one-cell distance limit and
therefore still left large holes. That limit is removed. GroundPart computes
eight-neighbour terrain components, including corner-touching stair tiles.
When a component touches the ribbon or its cap, SlopePart projects its column
tops to the ramp throughout the footprint. Independent islands below a floating
ribbon cannot activate fusion. Fusion remains derived: no authored tiles are
created, and moving/erasing/undoing recomputes or removes it.

The complete derived polygon drives editor selection, endpoint clearance and
runtime collision. Every bridge cell is drawn, including cells deeper than the
original two-row diagonal stamp. Those cells reuse the native53-choice atlas;
only the diagonal upper fringe overlays the body. Exterior side/bottom grass
is retained while interior grass and transparent gaps disappear. Standalone
ribbons stay thin. The old blanket “whole-cell air gaps stay empty” rule is
superseded; whether terrain is connected to actual contact is the criterion.

slope_fusion_test retains30 wedge samples across steep/gentle/both directions,
and now adds152 deeper samples across high-end/central-pillar profiles and both
directions. It checks real soil/edge RGB and actual runtime point collision,
independent islands, erase/undo/move and unchanged source-Part count. The RGB
oracle permits native brown exterior shading inside narrow one-cell shafts.
It does not accept green interior grass or background pixels. The old956-pixel
self-comparison alone missed these layouts.

Final import/five metadata checks and all54 native scenes pass, including the

- SlopePart/GentleSlopePart enable terrain page0 slots1/2, replacing the old
  slope/pipe-base placeholders. They are separate palette entries sharing one
  endpoint implementation. Defaults occupy3x2/4x2 grid bounds. Inclines remain
  exactly1:1 and2:1; this is not arbitrary free-angle rotation.
- Drag the body to move it; drag either circular end to resize. The untouched
  endpoint stays fixed, either axis can drive the edit, and crossing it flips
  the direction. One complete resize is one UndoRedo action, including origin,
  angle and extent. Place/move/erase also use native history. Invalid overlaps
  and course bounds reject the edit. This slice caps rise at11 cells; exact
  Nintendo maximum-size parity has not been asserted.
- GroundPart's existing53-choice atlas decision tree remains authoritative for
  ordinary cells and starting terrain. Slopes contribute occupied cells to
  the same map. Matching diagonal endpoints remove both flat caps, allowing
  consecutive steep/gentle segments to meet directly.
- Occupied cells follow the ribbon's upper AND lower profiles. Only endpoint
  caps use square atlas sprites; partial diagonal cells never produce square
  corners at5x5/6x6. Placement checks query the convex decomposition of the
  actual ribbon, not its convex hull or a bounding rectangle. A monster with
  a16px gap is allowed; a proposed cap intersecting the monster is rejected.
- Decorative atlas choices use a coordinate-seeded local RNG inside the same
  decision tree. Refreshes neither reroll the map nor consume the global RNG.
  GroundParts cache their unchanged topology/art, and slopes cache unchanged
  geometry/adjacency. Starting-ground cells use the same stable atlas choices.
- Diagonal grass reuses the native atlas's paired upper/lower slope regions.

  ground below absorbs the underside into the filled pair. Intersected authored

- User-drawn gentle PNG overrides belong in `textures/tiles/slopes/`. Read its

## Save contract and bounded scope

The pinned OpenWE has no usable endpoint save contract. Signed SWE files use
explicit `godotwe_slope`/`godotwe_gentle_slope` extension objects with
`slope_rise` and `slope_right`, preserving unknown fields and both existing
wrappers. Save/reopen is supported in this project. Opening these extension
objects in the original OpenWE executable is not supported or verified.

This slice implements solid **floor** ribbons, including suspended strips and
merging with existing staircase terrain. Ceiling editing, alternative stair
art, other styles/themes and exhaustive special-enemy interactions are not
completed. User-drawn final gentle textures are still pending. Do not advertise
full SMM2 slope parity or infer authorization for those follow-up features.
