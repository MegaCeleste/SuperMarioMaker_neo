## 实施要点

1. 小型形态允许下蹲姿态；碰撞箱保持小型站立尺寸，待实测。
2. 下蹲起跳后在整个空中阶段保持下蹲姿态，落地解除。
3. 刹车开始后保持至停下或完成反向，不在跌破进入阈值时提前结束。
4. 走/跑动画随水平速度提高帧率；跑姿工程预览改为达到 `run_max` 才切换。
5. 研究数据缺口写入 spec，不编造新数值。

## 验收标准

- [x] 小型形态下蹲时进入 CROUCH，站立碰撞形状保持启用。
- [x] 下蹲起跳后松开下方向，AIR 状态仍播放下蹲动画，落地后恢复。
- [x] 40 帧跑动仍为走姿，达到 `run_max` 后切跑姿，动画倍率随速度增大。
- [x] 反向输入降到 `skid_threshold` 以下仍保持 SKID 至归零或转向。
- [x] 未确定的原作数值已记录为 TBD 或待复测。
