## 什么时候记录

架构边界、保存格式兼容、重要依赖、跨平台取舍或成本较高的方向改变值得记录。普通 bug、换一个参数或修正帧索引不需要单独 ADR。

一页内写清日期与状态、背景、决定、原因/备选项、影响。必要时用新记录取代旧记录并链接，不需要维护逐条 REQ 或重新审批全部文档。
