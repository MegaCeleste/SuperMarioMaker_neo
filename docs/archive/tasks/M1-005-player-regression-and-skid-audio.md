## 完成回报

### 完成项

- 根因：本地 skid.wav 导入参数 edit/loop_mode=2，旧 Player 只在进入 SKID 时播放，离开时未停止。现为各实例复制音频流并清除循环标记；离开 SKID、变身和复位停止刹车声，死亡/复位清理所有残留效果音。共享媒体及本地导入文件不改写。
- 输入快照补上普通/旋转跳释放事件；即使停止积分的变身定格期间，也锁存已松开本次起跳按键的事实，重新按住不能恢复长跳重力。CSV 同时记录三种动作键的释放事件。
- 仪表盘增加 7 个入口及中英提示。复位回到所选入口，清理交互实体、声音、采样和计量；暂停状态下也立即更新相机。死亡会取消尚未完成的跳跃/加速/刹车计量。
- 调试几何和出生点集中于 data/debug/physics_dashboard.json；场地尺寸属于工程调试设计。
- 导出元数据升级为 schema_version=2：入口配置、记录起始 Profile、最终 Profile、样本起止位置、绝对样本索引的参数变更。解决记录超过 7200 帧后变更位置始终落在缓存末尾的问题。

### 试玩顺序

打开 src/gameplay/debug/physics_dashboard.tscn，运行当前场景；顶部下拉选择入口。A/D 移动、← 加速、↑ 跳、↓ 旋转跳、S 下蹲；R 复位、F6 暂停/继续、F7 单帧。

| 入口 | 观察重点 |
|---|---|
| 平地 | 加速到满速的帧数、满速跑/跳贴图、反向刹车声音和时长、长短跳 |
| 问号块 | 顶块、蘑菇变身、普通净空下不自动下蹲 |
| 16px 狭缝 | 默认大型且暂停；无下蹲输入时保持蹲姿，移出净空后站起；也可切小型对照 |
| 敌人 | 踩踏与侧面受击、长短弹跳、降级/免疫期间重复接触 |
| 平台边缘 | 默认暂停；走出平台，比较土狼窗口最后有效帧与第一无效帧 |
| 空中落地 | 默认暂停；比较缓冲窗口内落地与过期后一帧落地 |
| 天花板边缘 | 默认暂停；名义重叠 3px，可用纠偏距离 2/3px 对照并逐帧观察 |

一轮试玩调整后导出记录，可继续提供手感反馈；导出不会自动修改仓库基线或提升参数等级。
