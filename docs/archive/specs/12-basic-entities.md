## 道具

**REQ-PWR-014 火焰花实体**: 火焰花为独立场景，静止于地面并可从问号块升起。出块期间不受地形求解或拾取；结束后恢复碰撞/拾取。接触事件缓存，由安全物理帧请求 Player.collect_fire_flower；请求接受后只消耗一次。演出/死亡期间不吞掉道具。同级拾取不降级，形态仍由 PowerUpManager 管理。Fire 使用明确帧条、尺寸和锚点的专用 SpriteFrames，沿用满速跑/跳与速度动画契约；火球命中走现有统一击败入口。

**REQ-PWR-015 板栗仔搬运**: 板栗仔 Galoomba 与栗子仔 Goomba 分为独立场景。板栗仔常规踩踏进入 STUNNED，翻倒后不产生侧面伤害；接触时可按 run 搬运，未按 run 可踢出。搬运仅在 STUNNED 有效，沿用 ICarryable 与 Profile 的投掷值；HELD 不自行积分、恢复或伤害。释放/受击掉落恢复碰撞，投掷进入 THROWN，可击败接触敌人。恢复倒计时暂停于搬运和全局演出，倒计时结束恢复 WALKING。旋转跳/火球直接击败。恢复帧数属于工程候选。

**REQ-PWR-016 金币**: 场景金币通过安全物理帧拾取；问号块金币当次顶击请求一次奖励并播放弹出表现。计数采用 GameManager 会话计数信号，玩家金币音效使用无位置播放。试玩复位清理会话计数，不实现生命奖励或完整分数系统。

**REQ-PWR-017 火焰发射表现**: Fire 发射成功时，可在地面 IDLE/RUN 使用专用 shoot 姿态，其物理帧计时放入 data/physics/player_presentation，明确为工程表现候选。空中、蹲姿和刹车沿用原动画优先级，特别是满速跳贴图保持至落地的契约不得被发射表现打断。火球使用经尺寸/帧索引核对的本地帧条，运动仍来自 PlayerPhysicsProfile；动画与表现计时随物理暂停/演出冻结。

## 敌人、方块与时序

**REQ-PHYS-121 栗子仔**: Goomba WALKING 时沿地形巡逻，撞墙反向；普通踩踏进入 SQUASHED，停止伤害并于表现计时结束后删除；旋转跳、火球或被投掷实体命中走 DEAD 击败表现。敌人接触使用既有传感器，先处理踩踏再处理侧面伤害；只有可伤害的状态才请求受击。所有状态和计时在物理帧推进。

**REQ-PHYS-122 基础方块**: 问号块默认金币，允许 contained_item 选择蘑菇/火焰花；一次有效顶击后变为 EMPTY，禁止重复出物。显式用过的方块与硬块始终实心。SMW 翻转块顶击后转动并暂时取消地形碰撞，计时结束须确认体积净空才恢复；大型 SMW 旋转跳从上方撞击可破坏翻转块，并沿用 Player 弹跳参数。顶击与旋转击破均只选当前接触中水平重叠最大的块。方块弹性表现不得叠加并应保持网格碰撞稳定，可通过上方传感器通知敌人/道具受顶击。

**REQ-PHYS-123 实体生命周期**: 道具出块、敌人恢复/死亡、金币弹出和方块转动全部采用物理帧，受 GameplayFreezeGate 与场景暂停控制。碰撞回调只缓存交互，安全帧处理形态/运动/删除。可放置实体全部注册，通过 Registry 工厂应用合法导出属性；未注册对象报错。提供独立基础实体场景和仪表盘入口，复位清理所有运行实例，保留负责人已有主场景地形数据。
