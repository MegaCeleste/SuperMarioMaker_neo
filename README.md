# SMMneo

一个基于 Godot 4 引擎开发的《Super Mario Maker2》复刻项目。旨在通过Godot引擎，还原经典的 2D 平台跳跃手感与自由度极高的关卡编辑器体验。

---

## 🚀 项目现状 (Current Status)

目前项目处于**非常初期的原型阶段（Early Prototype）**。我们正在专注于打磨最核心的底层物理与交互逻辑。

### 已实现特性：
- 🎮 **核心状态机 (Player State Machine)**：基于状态机驱动的马里奥控制系统，已精准还原走、跑、跳、下蹲、惯性滑行及空中滞空感。
- 🧱 **基础方块交互 (Core Blocks)**：实现了几种最基础的方块物理碰撞与敲击反馈（如普通砖块、问号方块原型）。

---

## 🛠️ 技术栈 (Tech Stack)

- **Engine:** Godot 4.x
- **Language:** GDScript
- **Architecture:** 状态机模式 (State Pattern) / 组件化设计

## 🤝 参与贡献 (Contributing)

这是一个完全开源的项目，我们非常欢迎感兴趣的开发者、像素艺术家（Pixel Artists）以及关卡设计师加入，一起把这个世界变得更丰富！

### 如何帮我们改善项目？
1. **Fork** 本仓库。
2. 克隆到本地，在 Godot 4 中打开。
3. 创建你的功能分支 (`git checkout -b feature/AmazingFeature`)。
4. 提交你的修改并推送到你的仓库。
5. 在本仓库提交一个 **Pull Request (PR)**。
