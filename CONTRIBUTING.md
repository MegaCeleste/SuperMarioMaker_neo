Contributing to GodotWE
================================================================================
### Contributions are welcome!

We would love for you to improve GodotWE! However, you should follow these rules
on how to write code for GodotWE. Don't worry if you might've not followed them,
as I always will review changes and check them accordingly. There is also a lot
to fix up!

1. Follow the
   [GDScript style guide][1]. This already covers almost everything you need to
   know when writing GDScript.
2. **Use comments!**
   - Put [documentation comments][2] on all public class members. GodotWE is
	 meant to be easy to work with, and documentation helps that immensely.
   - Put regular comments on sections of code that could be found confusing,
	 even with the surrounding context.
3. Commits must follow the [Conventional Commits][3] standard.
4. When merging pull requests, it must be squashed to maintain a clean commit
   history. `Co-authored-by` trailers must also be added to the merge commit for
   each person who had committed to the pull request. Everyone deserves credit!

Joining the community
--------------------------------------------------------------------------------
As a contributor, you should join our [Discord server][4] to keep up with news
and communicate with the community.

### Thank you for considering and enjoy your time with GodotWE!
