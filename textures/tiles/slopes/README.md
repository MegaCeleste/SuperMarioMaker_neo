# SMW 斜坡补图清单（2026-10-23）

**普通方块地面、背景不缺素材，不需要重画。** 切主题后的普通地面错乱是
源素材帧号与存档帧号混用，已修正映射。斜坡是另一件事：地上陡坡有原图，
地上缓坡尚未收到成品；地下有部分斜角帧，但并非当前窄坡需要的完整组合，
另外四个主题也没有完整的斜坡组，目前使用临时派生图。

最优先补 **地上缓坡四张**，仍可放在本目录，旧文件名继续有效。
如果同时补各主题，建议使用以下目录。每张图都可以单独提供，保存后重启
项目自动导入；没有提供的部分继续临时显示，不会阻止游戏运行。

| 主题 | 子目录 | 还需提供的完整组 |
| --- | --- | --- |

| 文件 | 原始尺寸 | 内容 |
| --- | --- | --- |
| `steep_up.png` | 16×32 | 向右上升的45°独立窄坡，上沿和下沿均有外缘 |
| `steep_down.png` | 16×32 | 向右下降的45°独立窄坡 |
| `steep_up_filled.png` | 16×32 | 上升接地坡，上方透明，下方连续填入本主题内部材质，不画下外缘 |
| `steep_down_filled.png` | 16×32 | 下降接地坡 |
| `gentle_up.png` | 32×32 | 向右上升的2:1独立窄坡 |
| `gentle_down.png` | 32×32 | 向右下降的2:1独立窄坡 |
| `gentle_up_filled.png` | 32×32 | 上升接地缓坡 |
| `gentle_down_filled.png` | 32×32 | 下降接地缓坡 |

上升坡上沿从左侧y=15到右侧y=0，下降坡反向；缓坡每横向2像素升降
1像素，陡坡每横向1像素升降1像素。独立坡在上沿下方保留纵向16像素
厚度，之外透明。画布完整保留两行16像素图块，不能裁透明区。
坡两端的平地端点由现有方块地面自动连接，无需另画端点或阴影。
使用PNG、透明背景和原始像素尺寸，不要放大或加抗锯齿。

编辑器、试玩和对应主题调色盘共用这些文件。`overworld/`中的同名文件
优先于本目录旧路径。地上陡坡图标仍沿用已有原版图标。

## 原有地上缓坡路径

把重新绘制的 PNG 直接放在这个目录，保持原始像素尺寸和透明背景：

| 文件 | 尺寸 | 内容 |
| --- | --- | --- |
| `gentle_up.png` | 32×32 | 向右上升的独立窄坡段，含上沿和下沿的草边 |
| `gentle_down.png` | 32×32 | 向右下降的独立窄坡段 |
| `gentle_up_filled.png` | 32×32 | 向右上升、与土地合并时的坡面；下方为土色，不画下沿草边 |
| `gentle_down_filled.png` | 32×32 | 向右下降、与土地合并时的坡面 |

每段水平32像素、垂直升降16像素；上半16像素是一行图块，下半
16像素是下一行。独立坡段的碰撞厚度为纵向16像素。端点平地仍使用
现有 `../ground.png` 和 GodotWE 的土地连接规则。

`templates/` 中的四张 PNG 是当前临时素材的原尺寸绘制模板，可复制到
本目录后修改。模板本身不会自动启用。**这些是占位参考，不是最终缓坡美术。**
文件允许逐张提供，缺少的方向或合并版本继续使用临时素材。

保存后重新运行项目，Godot 会自动导入并启用对应贴图；编辑器、运行时和
缓坡调色盘图标共用素材。请不要放大、裁去透明区域或使用 JPG。
