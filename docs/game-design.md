# 游戏设计

更新：2026-10-09。本文描述当前采用的玩法与长期方向；数值看 `data/`，完成度看 roadmap。

## 目标与当前范围

SMMneo 是以 Super Mario Maker 2 为主要参考的 2D 平台跳跃和关卡创作项目。近期目标是稳定、可反复试玩的玩家和基础交互，随后把编辑器“创作 → 试玩 → 返回修改”做成完整循环。

当前提供SMW玩家/场景表现、SMB1/SMB3/SMW能力配置及分区实体试玩。Goomba、Galoomba之外新增红绿龟、钢盔龟、刺刺、炸弹兵和四向食人花；新增星星、1UP、10/30/50金币。负责人确认SMW中的Goomba先使用标记的SMB1行走/踩扁美术占位；Galoomba保持SMW美术与翻倒身份。新增对象本轮只制作SMW地面白天；完整多风格换皮、关卡分享与移动端体验仍未完成。

## 玩家行为

以下已根据负责人反馈采用，后续修改时应有明确原因与试玩反馈：

- 行走到跑步姿态只有在水平速度达到 `run_max` 时切换。动画相位随实际水平位移累积，速度越快切帧越快；stride 仍是工程候选。
- 普通满速起跳使用满速跳贴图，空中减速、松开跑键、越过顶点都保持，直到落地。蹲跳和旋转跳有自己的姿态优先级。
- SMB1/SMB3/SMW 小型形态都可下蹲。蹲着起跳后保持蹲姿直到落地；碰撞盒的精确 SMM2 数值仍待测量。
- 长短跳由本次起跳的按键保持控制；释放后锁存短跳，不因再次按住而恢复长跳。定格期间也保留释放边沿。
- 松方向用自然摩擦；反方向用刹车力。进入 SKID 后保持刹车直到归零、完成换向、松开反向输入或离地。
- SKID 期间刹车声持续循环，退出状态/变身定格/死亡/复位时停止。玩家音效和主场景 BGM 不随世界距离衰减，其他事件声音单次播放。
- 刹车脚边播放SMW专用五帧烟尘，留在发射位置；退出刹车停止发射，暂停/定格停止计时，死亡/复位清理。旋跳秒杀的怪物立即消失，只留下星光，没有烟雾或飞出地图的尸体；板栗仔翻倒复用原行走图上下翻转。
- 空中无方向输入时保持水平动量；同向输入不把高于步行上限的速度强制压低。
- 土狼时间、跳跃缓冲和擦角纠偏是当前内置手感辅助。是否属于 SMM2 原生及精确原值分别记录，不能以工程实现证明原版算法。
- 当前只有一个普通最高跑速；候选 P-Meter 不改变速度上限、跑姿或跳高。未来飞行用途另行设计。
- 净空不足时保持蹲姿，避免变大/站起穿过天花板。

最高跑速等来源在 `data/physics/player_parameter_evidence.json` 中保存。本次文档迁移保留历史证据等级，不重新声称所有物理已验证或调校完成。NSMBU 的 800 刹车逆向值仍只是对照，不能直接当成 SMM2 实测。

2026-10-08 按负责人要求，默认普通地面/空中运动采用 SMMWE 4.0.0 白天 SMW 源码的 16px/60Hz 换算：走 78 / 跑 180，同向加速 216，地面与空中反向 468，松方向摩擦 180、地面超速另减 90；普通跳按起跳前速度取 −237 / −243 / −258，旋跳 −198，上升/下落重力 360 / 1080，vy>−30 提前锁存大重力。最高速度为分支门槛，允许参考源码的一小步超出；落速 240 为加重力前阈值，实际普通下落步可用 258px/s。顶头归零，普通踩踏按住/松开初速均为 −253.5，保持键决定重力。

此配置供试玩，尚未由负责人认可，也不认作官方 SMM2 原值或完整 GameMaker 移植。碰撞盒、步频、特殊地形/道具/死亡仍沿用工程实现；上述姿态锁和输入辅助继续采用。仪表盘可在“SMMWE 参考物理”和“调整前物理”间切换并复位，旧值保存在 `pre_smmwe_physics.tres`。详细数值与复现见 [同步记录](plans/2026-10-08-smmwe-physics-sync.md)。

## 形态与能力

当前使用的项目转换：

| 当前形态 | 事件 | 结果 |
|---|---|---|
| Small | 蘑菇 | Super |
| Small / Super | 火焰花 | Fire |
| Fire | 普通受击 | Super |
| Super | 普通受击 | Small |
| Small | 普通受击 | Dead |
| 存活形态 | 强制死亡 | Dead |

同级/低级道具不让玩家降级。变身/降级以独立演出阶段处理，保留运动动量并冻结当前 gameplay 实体；演出期间的普通拾取/伤害请求不生效，强制死亡可中断。受击无敌期从降级演出结束后开始，时长由 Profile 提供。死亡只进入一次，显式复位后才能重新行动。

这是当前项目采用的梯级规则，未全部完成 SMM2 原生转换核验。坠落深渊、挤压、计时器可以使用强制死亡入口，但完整关卡危险/超时系统尚未接通。

Fire点按逻辑`run`发射火球，限制同时数量与冷却。地面短暂显示发射姿态，空中满速跳锁定不被打断；搬运时不发射。火球沿地形弹跳，由各怪物的类型命中接口决定结果：钢盔免疫仍消耗火球，炸弹首发点燃、后续推开，食人花需露出达到攻击门槛。

星星独立于形态，持续600个活动物理帧，重复拾取刷新600。期间普通伤害免疫、接触击敌、颜色循环，走/跑速度门槛临时加30px/s；到期移除加成，超速沿用既有减速。暂停/变身定格停止计时，强制死亡仍有效，死亡/复位/退出清理效果。

SMW 支持旋转跳、搬运和高抛；SMB3 配置支持搬运；SMB1 不支持搬运。非旋转风格的旋转跳输入降级为普通跳。能力开关中的 yoshi 只是预留，骑乘系统尚未实现。

## 基础交互

| 对象 | 当前玩法 |
|---|---|
| 栗子仔 Goomba | 沿地形走动、撞墙换向；普通踩踏后踩扁消失；旋转跳/火球/投掷命中击败 |
| 板栗仔 Galoomba | 普通踩踏后翻倒；翻倒时可按跑键抓取、不按跑键接触踢出；松开跑键投掷，SMW 可高抛；倒计时恢复，搬运和演出时暂停计时 |
| 蘑菇 | 地面移动，撞墙换向；拾取升级；出块期间暂不拾取 |
| 火焰花 | 静止地面道具，可从问号块升起，拾取进入 Fire |
| 金币 | 场景接触或问号块顶击奖励一次，更新会话金币计数 |
| 红绿龟 / 壳 | 绿龟走落悬崖，红龟边缘转向；普通踩踏脱壳，独立无壳龟可跳回同色空壳；壳可踢、踩停、搬运、高抛、撞墙反弹及连续击敌 |
| 钢盔龟 / 刺刺 | 钢盔龟踩缩壳、火球免疫；刺刺普通踩踏伤害、旋跳安全反弹；顶块可翻倒，恢复检查净空 |
| 炸弹兵 | 点燃、踩停、踢出、抓取和投掷；300活动帧引信在手持时继续，不因状态转换刷新；爆炸只结算每个目标一次 |
| 食人花 | 四向固定管口，按露出长度改变碰撞；近口抑制伸出，隐藏无伤害；本轮管口是静态地形 |
| 无敌星 / 1UP / 大金币 | 星星可场景放置和出块；1UP增加会话获得额外生命；10/30/50金币只场景放置，一次性增加金币 |
| 问号块 | 默认金币，可选蘑菇/火焰花/星星/1UP；顶击、壳侧撞或爆炸后变已用块，不重复出物 |
| 已用块 / 硬块 | 保持实心，顶击音效反馈 |
| SMW 翻转块 | 顶击后转动、暂可穿过；净空后恢复；大型旋转跳从上方可击破 |

顶击/旋转击破一次只选水平重叠最大的块。顶块只移动画面，保持网格地形稳定并通知块上敌人/道具。爆炸可以破坏硬块/翻转块（含转动中），不改TileMap。HUD显示金币、获得额外生命、星星剩余帧；没有生命耗尽/Game Over或完整计分系统。交互矩阵与适配见[实体来源记录](research/2026-10-09-smmwe-entities.md)。

## 编辑器第一轮

已实现独立F6场景。负责人否定首版布局后，明确指定提供的SMM2截图为视觉基准，现改为全屏SMW画布、半透明浮动工具区、原图卡片/分类色条、左侧设置、右侧菜单/Coursebot/橡皮擦/狗/火箭、左下试玩板和右下主区域。顶部十二物件按截图顺序排列；未注册物件只展示禁用图标，可用物件仍来自Registry。确实缺失的界面图标按负责人要求留空。

主区域240×27格、世界网格16px、初始逻辑缩放2倍；1920×1080初始显示每格80px，窗口同比例缩放。中键平移、滚轮鼠标锚点缩放（逻辑1～4倍）；菜单内位置滑条同步相机。B/E/V切工具，G网格，Tab圆环，Esc关闭；切换擦除后顶部仍保留当前物件的深色卡片和固定标记。

调色盘按后续图6采用全屏十槽圆环：浅粉外环、虚线分隔、分类色中心、白色物件卡、顶部选中分类长条和翻页箭头。地形包含方块，另有道具/敌人/机关。现有图标可以展示，只有Registry已有物件可选；本批新增怪物/物品和壳已接入静态预览及选择，未注册图标和空槽保持无操作。

负责人要求移除提示气泡和说明弹窗；未接通的关卡设置/Coursebot仅保留禁用入口。工具栏按钮悬停显示橙红四角三角；调色盘分类/翻页按钮及物品不显示四角，物品悬停以分类色填满对应扇区并连接中心圆。圆盘使用圆形绘制，不吸附圆周点。物件图留在白卡内，ArtView与CapView子节点可直接调整；背景使用最近邻像素采样。界面统一英文并使用fonts目录字体，不使用系统默认字体。

本轮只建立界面和状态；点击画布不放置、擦除或选择真实对象，不修改关卡数据。关卡仍固定为SMW/地面/白天/300秒/无卷轴；存读、撤销/重做、重置、试玩和副区域未接通。技术检查与负责人视觉/操作认可分开记录。

## 后续体验方向

- 编辑器：16px 网格绘制/擦除/选择/属性修改、撤销重做、平移缩放；编辑数据与试玩实例分离。
- 关卡：存读、起点与终点、计时器/通关、主副区域、管道、房间卷轴与相机。
- 更多对象：翅膀/降落伞、ON/OFF、P开关、POW、钥匙、耀西与高级形态；爬顶钢盔、刺球/可佩戴刺壳、喷火/跳跃花另行推进。
- 用户体验：手柄/触屏、键位设置、中英界面、音乐/SFX 分轨和关卡仓储。
- 可选视觉增强：法线贴图动态光影，默认关闭；只影响画面，不改变碰撞/物理。算法、资产覆盖顺序与移动端预算应在实际开发时决定。
